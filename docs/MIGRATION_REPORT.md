# 이관 보고서

## 무엇을 했나 / 하지 않았나
| 항목 | 결과 |
|---|---|
| 사용자 데이터 삭제·초기화 | **하지 않음** (승인 요청 사유 없음) |
| 기존 DB(`poker-arena`) | 읽기 전용으로만 접근, 원본 무변경 (테스트로 확인: `tests/legacy.test.ts`) |
| TETO 실제 플레이 기록 내용 | **미확인** — 기록은 사용자 기기 브라우저에만 있고 이 클라우드 세션에서는 볼 수 없다. 임의 수치를 부여하지 않았다. |
| 이관 도구 | 앱 내 자동 복사(`importLegacyInto`) · 전체 백업(JSON+SHA-256) · `scripts/legacyProfile.ts` · 계정 화면의 「내 플레이 성향 — 저장된 기록 기준」(표본 크기·신뢰도·일시 미확인 표기) |
| 발견·수정한 이관 버그 | IndexedDB 트랜잭션을 연 채 다른 DB를 `await` 하면 트랜잭션이 종료되는 문제 → 원본을 먼저 모두 읽고 한 번에 쓰도록 수정 (테스트가 먼저 실패 확인) |

## 이관 후 해석 규칙
- 핸드 아카이브·상대 관찰(`memory`)·대회 전적·설정: 복사. 옛 전적은 `legacy/unverified`(원장 근거 없음) — ROI/랭킹 점수에 반영하지 않는다. 새 시즌 지표는 서버 기록부터.
- 옛 통장 잔액: 보고서에만 남기고 새 지갑(서버 30,000)에는 반영하지 않는다.
- TETO 사용자명 재사용: 새 계정 가입 시 아이디를 `TETO`로 만들면 된다(아이디는 대소문자 무시 유일). 기기 로컬 기록은 같은 기기에서 가입할 때 복사된다. 다른 기기라면 먼저 기존 기기에서 백업을 받는다.

## 사용자가 해야 할 일 (선택)
1. 기존 기기에서 앱 열기 → 계정 화면 → 「전체 백업 내려받기」(안전장치).
2. 같은 기기·브라우저에서 새 앱 버전으로 접속해 가입 → 기록이 자동 복사됨. 「내 플레이 성향」 카드에서 핸드 수와 지표를 확인.
3. 파괴적 초기화는 필요하지 않다. 정말 초기화를 원하면 요약과 백업 경로를 보여 준 뒤 1회 승인을 받는다.
