# 01 · 이관 계획

원칙: **삭제·초기화는 하지 않는다.** 모든 단계는 복사/추가이며 원본은 보존한다. 파괴적 초기화가 필요해지는 경우에만 요약+백업 경로를 보여 주고 사용자의 1회 명시적 승인을 받는다 (이번 작업에서는 **파괴적 초기화를 수행하지 않았다**).

| 단계 | 동작 | 롤백 |
|---|---|---|
| 0 | 설정 > 「전체 백업 내려받기」 (JSON+SHA-256) — 사용자가 직접 | 해당 파일로 복원 |
| 1 | 로컬 모드: 기존 DB `poker-arena` 그대로 사용 | — |
| 2 | 계정 가입/로그인 시 새 DB `poker-arena-<accountId>` 생성 후 `archive/memory/tourneys/settings` **복사** (`legacy_import` 보고서 저장) | 새 DB만 삭제하면 됨, 원본 무변경 |
| 3 | 지갑은 서버 원장에서 시작(30,000 크레딧 · 서버 확정). 옛 잔액은 `legacy/unverified` | — |
| 4 | 옛 전적/통계는 `legacy`로 구분, 새 시즌 지표는 서버 기록부터 | — |
| 5 | 서버 DB 스키마는 `CREATE TABLE IF NOT EXISTS`(추가만) | 파일/D1 백업 |

복원 실패 시: 이관은 트랜잭션(IndexedDB 단일 트랜잭션)이며 실패하면 새 DB가 비어 있는 채로 게임이 시작된다(게임을 막지 않음). 이미 이관된 경우 `legacy_import` 키로 중복 복사를 막는다.
