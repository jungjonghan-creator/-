## 상금 구조 (`src/world/prizes.ts`, 서버·클라이언트 공용)
- 상금 풀 = (바이인 − PKO 바운티 몫) × 엔트리 + 보장 오버레이. 수수료는 풀에 포함하지 않는다. Σ상금 = 풀(잔여 1칩 단위는 우승 상금).
- 입상 인원 = 엔트리 × ITM%. 최소 입상액 ≥ 바이인의 1.1배를 만족하도록 지수(1.3→0.3)를 탐색, 비증가.
- 총 엔트리가 변하면(레이트 등록·재진입) 상금표를 다시 계산하고, **탈락 시점의 순위와 그 시점 상금표**로 즉시 지급한다.
- 헤즈업 표: 같은 라운드 탈락자는 공동 순위(상금 균등, 홀수 칩 1 차이).
- 랭킹 점수 규칙은 `RANKING_MODEL_v2.md` / 앱의 「점수 산식 공개 보기」.

## 대규모 필드 시뮬레이션
사용자 테이블은 풀 엔진(AI 의사결정 포함). 나머지 테이블은 **배치 시뮬레이터**(`src/world/batch.ts`): 실제 52장 덱·실제 평가기·실제 블라인드/앤티·사이드 팟·콜 안 된 베팅 반환, 의사결정은 프리플랍 퍼센타일+포스트플랍 강도 추정의 휴리스틱(풀 엔진의 MC 의사결정이 아니므로 **근사**). 모든 테이블 핸드에서 칩 보존을 검사하며 특정 선수에게 칩을 임의로 주지 않는다. 실력 반영도는 `npm run bench:world 1`로 측정(문서 `TEST_REPORT.md`). 벤치마크는 `TEST_REPORT.md` 참고.
