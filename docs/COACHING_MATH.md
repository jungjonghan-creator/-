# 분석실 수학 · 정직한 표기

모든 수치는 **정확 / 몬테카를로 / 휴리스틱** 배지로 구분한다. 「GTO 확정값」「솔버 정확도」「정확한 EV 손실」이라는 표현은 쓰지 않는다. 유료 솔버·외부 API·LLM 의존성 없음 (로컬 규칙·확률·템플릿).

## 정의
- 팟오즈 필요 승률 = **콜액 / (콜 직전 팟 + 콜액)** (정확). 올인 EV는 가능한 런아웃 전체의 승률(몬테카를로 또는 열거)로 계산.
- 승률(Equity): 상대 카드가 알려져 있으면 열거, 모르면 **가정한 레인지**에 대한 몬테카를로. 시드·반복 수·표준오차 `√(p(1−p)/N)` 표시. 「실측/가정」 구분.
- 폴드 에퀴티/블러프 EV: 상대 폴드 확률은 **추정**이며 가정에 민감하다고 명시. 아직 모르는 카드를 본 것처럼 분석하지 않는다(문제 생성 시 미래 카드·내 행동·결과 제외).
- ICM: 정확한 Malmuth–Harville는 n≤9일 때만 「정확」, n>9는 같은 모델의 몬테카를로(표준오차 표시). 모델 한계(스킬/포지션/바운티 미반영)를 노트로 표시. 대규모 필드·PKO 리스크 프리미엄은 휴리스틱.
- 프리플랍/포스트플랍 연구소: 13×13 격자와 C-벳 가이드는 **경험칙 기반 기초 레인지**(169핸드 승률표 순서 + 포지션 임계값)이며 솔버 해가 아니다.

## 탭별 책임
| 탭 | 내용 | 정확도 라벨 |
|---|---|---|
| 종합 리포트 | 누수·운 보정(올인 EV)·틸트·상대별 공략·훈련 계획 | 몬테카를로 |
| 리플레이·복기 | 단계별 재생, 결정 시점 정보·팟오즈·대안. 숨은 상대 카드는 「알 수 없음」 | 정확+몬테카를로 |
| 프리플랍 | 포지션×스택(10~100BB)×앤티, RFI/BB 방어/3벳 대응/푸시폴드 | 휴리스틱 |
| 포스트플랍 | 보드 질감, 레인지 우위, SPR, C-벳 크기·빈도 가이드 | 휴리스틱 |
| 토너먼트·ICM | ICM 가치, 올인 손익분기 승률, 리스크 프리미엄, 버블 팩터 | 정확/몬테카를로 |
| 약점 지도 | 주제×스택×베팅 크기 교차표, Top3. 표본 8개 미만 칸은 수치 비표시 | 몬테카를로(추정 EV) |
| 맞춤 훈련 | 사전(15)→해설→**독립** 사후(15)→7일 복습→실전 변화 | 몬테카를로 |
| 상대 데이터 | 공개 행동/쇼다운 기반, 표본 크기·신뢰도 | 추정 |
| 경제 감사 | 원장=계정=전적 합계 비교 | 정확 |

## 향상 선언 기준 (사전 고정, `TRAINING_RULES`)
문항당 15개 이상, 정답률 +15%p 이상일 때만 「기준 달성」. 이는 학습 효과의 간접 지표이며 **실력 향상은 이후 실전 같은 상황 지표(최소 30결정)로 따로 확인**한다. 표본 부족이면 판정을 보류한다.

## 심층 추론 엔진 (`src/analysis/deep.ts`) — 결정 복기의 계산 방식

**무엇이 달라졌나.** 예전: 상대 레인지를 "프리플랍 상위 x% + 현재 보드 강도 상위 y%" 두 숫자로 추정하고, 콜/폴드만 팟오즈로 채점(벳·레이즈는 점수 없음). 지금: 상대 한 명마다 1,326개 콤보의 확률(가중치)을 두고 **공개된 행동을 순서대로 하나씩** 반영한다.

1. 프리플랍 오픈/림프/콜/3벳/잼 → 포지션·테이블 인원·스택(≤20BB 잼은 푸시 범위)·앞선 림퍼별 우도.
2. 포스트플랍 벳(크기 b=팟 대비), 체크, 콜(최소방어빈도 기반 분위 컷), 레이즈 → **그 시점 레인지 안에서의 보드 강도 분위**에 대한 우도. 드로우(플러시/스트레이트 드로우)는 약해도 벳/콜하는 비중을 따로 둔다.
3. 같은 상대의 이전 스트리트 정보가 누적되므로 "플랍 체크-콜 → 턴 큰 벳"은 "플랍 벳 → 턴 벳"과 다른 레인지가 된다.
4. (선택) 같은 상대의 관찰 통계(VPIP/PFR/폴드-투-C벳, 25핸드 이상)가 있으면 오픈 폭·3벳 빈도·콜 컷을 보정한다.

**선택지별 EV.** 영웅의 한 결정에서 폴드/콜(체크)/벳·레이즈(팟 33·50·75·100·150%, 올인, 내 실제 사이즈)를 **같은 난수 표본(공통 난수)**으로 평가한다. 벳의 폴드 확률은 상대 레인지 콤보별 "계속 확률"로 계산(전원 폴드 = 곱), 계속 시 승률은 계속하는 콤보 가중 평균. 이후 스트리트는 실현율 상수(IP/OOP·인원 수)로 단순화. 손실 = 최선 EV − 내 선택 EV, 그 **표준오차**를 함께 계산하고, 손실이 2σ·팟의 4%·0.25BB 중 큰 값을 넘을 때만 「실수(추정)」로 표기한다(그 외는 경계선).

**한계(숨기지 않음).** 솔버가 아니다. 단일 스트리트 EV(이후 스트리트는 상수), 상대 행동 모델은 휴리스틱 우도(백테스트로 보정), 3인 이상 멀티웨이 폴드 확률은 독립 가정, 프리플랍 첫 오픈은 여전히 포지션별 범위표로 채점(rigor=heuristic).

**백테스트(`npm run backtest:range`).** AI끼리 친 핸드에서 관찰자 좌석이 공개 정보만으로 계산한 승률 추정치를, 상대의 실제 홀카드에 대한 몬테카를로 승률(300회)과 비교. 실제 패 대비 승률은 본질적으로 양극(이기거나 지거나)이라 RMSE 하한이 0이 아니다 — **옛 방식과의 상대 비교**로만 읽는다.

| 지표 (세션 10개, 결정 1,364개) | 옛 방식 | 심층 추론 |
|---|---|---|
| 전체 RMSE | 0.2121 | **0.1910** (−10%) |
| 편향(추정−실제 평균) | −0.040 | +0.022 |
| 플랍 / 턴 / 리버 RMSE | 0.232 / 0.290 / 0.384 | **0.212 / 0.256 / 0.345** |
| 헤즈업 RMSE | 0.256 | **0.231** |
| 상대 실제 패의 평균 로그우도 | — | −6.58 (균등 가정 −7.07, +0.49 nats) |

옛 방식은 레인지를 너무 넓게(승률 과대추정 → 과콜 판정 위험) 보는 편향이 있었고, 새 방식은 반대로 소폭 낙관 편향이 남는다. 개선폭은 10% 수준이며 "정답 판정기"가 아니라 "더 나은 추정치 + 오차 표시"다.
