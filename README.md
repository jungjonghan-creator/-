# ♠ POKER ARENA 5.0

가상 칩 기반 개인용 **노리밋 텍사스 홀덤** 시뮬레이터 (실제 돈 없음). 사용자 = TETO, 대표 AI 상대 = NOVA.
TypeScript(strict) · React · Vite · Tailwind · Zustand · IndexedDB · PWA · Vitest · fast-check · Playwright.

## 실행

```bash
npm install
npm run dev          # 개발 서버 (http://localhost:5173)
npm run build        # 타입체크 + 프로덕션 빌드 (PWA 포함)
npm run preview      # 빌드 결과 미리보기
```

외부 API·서버·유료 데이터가 필요 없습니다. 첫 로드 후에는 오프라인에서도 플레이됩니다(서비스워커).

## 테스트

```bash
npm test             # 엔진/AI/저장/MTT 단위·속성·시뮬레이션 테스트 (Vitest)
npm run e2e          # Playwright E2E (데스크톱 + 모바일 프로젝트). 사전 설치된 /opt/pw-browsers/chromium 이 있으면 자동 사용
npm run sim -- 2000  # AI 성향별 통계/난이도 시뮬레이션 리포트
npx tsx scripts/difficulty.ts 12000   # 난이도 우열 대표본 검증
npx tsx scripts/genPreflop.ts         # 프리플랍 순위표 재생성 (src/ai/preflopTable.ts)
```

## 게임 모드

**스토리 모드(더 서킷)**: 메뉴 → 스토리 모드. 자본이 세션 간 이어지는 4챕터 캠페인. 핸드가 끝나면 자동 코치 카드가 뜨고, `분석실`에서 누수 진단·올인 EV 운 보정·상대별 공략·훈련 계획을 볼 수 있습니다.

캐시게임(2/6/9인, 20/50/100BB·사용자 지정, 리바이·탑업) · 헤즈업 싯앤고 · 6/9인 싯앤고 · 멀티테이블 토너먼트(18/27/45/90명, 테이블 해체·균형·버블·파이널 테이블·재진입·ICM 사후 분석) · 푸시/폴드 훈련 · 상황별 스팟 훈련 · 훈련 테이블(요청 시 힌트).
실전/경쟁 모드에서는 행동 전 힌트가 제공되지 않습니다. 훈련 기록과 경쟁 기록은 통계에서 분리 집계됩니다.

## 정확성·공정성 설계

* 덱은 핸드 시작 시 확정(Fisher–Yates + 편향 없는 정수 추출)되고 핸드 중 변하지 않습니다. 난이도/사용자와 무관하게 동일 알고리즘.
* 모든 칩은 정수. 핸드마다 `스택+투입 = 총칩` 불변식 검사, 미대응 베팅 반환, 다중 사이드팟, 홀수 칩(버튼 왼쪽부터) 처리.
* 불법 행동은 UI가 아니라 **엔진이 거부**합니다(`validateAction`). 중복 클릭은 의사결정 토큰으로 무시됩니다.
* AI 의사결정 함수는 `Observation`(본인 홀카드·공개 정보만)만 받습니다. 상대 홀카드·덱은 구조적으로 전달되지 않으며, 테스트로 검증합니다(상대 카드/미래 카드를 바꿔도 결정이 동일).
* 저장은 IndexedDB. 불러올 때 스키마·덱 위치·칩 보존·모든 핸드 기록 리플레이를 검증하며, 손상 시 **조용히 복구하지 않고** 오류를 표시합니다.
